# MS Sans Serif

The site's interface font, as Windows 98's (css/ms-sans-serif.css): recreations of MS Sans Serif, drawn on the pixel grid of its 8 point size (11 pixels), where it renders as it did on Windows.

- **MS Sans Serif** by [lou](https://fontstruct.com/fontstructors/38403/lou), made with FontStruct, 2017: https://fontstruct.com/fontstructions/show/1384746/ms-sans-serif
- **MS Sans Serif Bold** by [lou](https://fontstruct.com/fontstructors/38403/lou), made with FontStruct, 2017: https://fontstruct.com/fontstructions/show/1384862/ms-sans-serif-bold

Both are licensed under [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/) (CC BY-SA 3.0).

The WOFF and WOFF2 files are the conversions published with [98.css](https://github.com/jdan/98.css) (`fonts/converted/`, npm package `98.css@0.1.21`), unchanged.
